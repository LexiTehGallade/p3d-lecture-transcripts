This repository contains hand transcripts of the Panda3D lectures uploaded by David Rose onto his Youtube Channel.

These videos are valuable documentation for Panda3D, but suffer from audio quality issues and lack of captions, as well as being uploaded onto a channel that could disappear at any time.
Note that these lectures date back to 2003-2008 and may not reflect the current state of the Panda3D engine in all aspects. 

If you feel like contributing, feel free to open a pull request with transcripts or changes.
